# For coding agents

Before any work in this repo, read [CONTRIBUTING.md](CONTRIBUTING.md) and follow it. In short:

1. **Always read [docs/plan/overview.md](docs/plan/overview.md) first.**
2. **Then work from the plan of the track you are assigned to.** Andrew has track A (evaluation,
   [docs/plan/track-a-evals.md](docs/plan/track-a-evals.md)). Wilson has track B (retrieval,
   [docs/plan/track-b-retrieval.md](docs/plan/track-b-retrieval.md)). Andre has track C (memory,
   [docs/plan/track-c-memory.md](docs/plan/track-c-memory.md)). If you cannot tell whose agent
   you are, ask.
3. **Be aware of the other two tracks:** read where they meet yours (CONTRIBUTING.md §1 and §3).
4. **Read the work log when you start, and write to it every time you finish a piece of work**
   (CONTRIBUTING.md §4).

This file and [AGENTS.md](AGENTS.md) say the same thing. Keep them the same.
