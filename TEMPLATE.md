# One line: what was finished

- **Track:** A, B, C or shared
- **Who:** the person, and the agent if one did the work
- **When:** YYYY-MM-DD HH:MM UTC
- **Work package:** for example A1, from the plan. "None" if none
- **Branch, commits, pull request:** where the work is

## Done

What now exists and works. Be specific: commands, files, numbers.

## Checked

How it was verified: the command that was run and what it showed. If something was not checked,
say so here.

## Left

What is still open in this piece of work.

## Blocked on, or needed from others

Who needs to do what, and by when. "Nothing" if nothing.

## Next

The next step, and who takes it.
